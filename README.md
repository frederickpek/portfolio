# Portfolio

Personal site for [Frederick Pek](https://github.com/frederickpek).

**Live:** [frederickpek.github.io/portfolio](https://frederickpek.github.io/portfolio/)

## What it is

A static portfolio built with React, Vite, and Tailwind. Project and activity data are pulled from GitHub and LeetCode ahead of time (local scripts and GitHub Actions), then served as JSON—nothing hits those APIs from the browser.

## What it shows

- **Activity** — a single year-long heatmap combining GitHub contributions and LeetCode submissions, with summary stats
- **Projects** — cards for selected repositories (description, language, topics, links to the repo and live demos when available)
